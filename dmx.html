DMX interface

Uses the Enttec DMX USB PRO protocol (also implemented by most inexpensive USB-DMX interfaces) over the Web Serial API. Chrome/Edge/Opera on desktop only -- not Firefox, not Safari, and not inside most wrapped mobile apps. Won't drive a raw "Open DMX USB" dongle or talk Art-Net/sACN directly.

Live inputs

Only enable what your fixtures actually use -- each is a separate permission prompt.

Fixtures

Each fixture patches a block of DMX channels to a live signal. Start channel is 1-512; channels used depend on the profile (e.g. RGB uses 3 consecutive channels starting there).
