Sensor Bridge

Talks to an ESP32/Arduino-class board (or anything else on the other end of a USB-serial chip) over the Web Serial API -- the same connection this suite's DMX page already uses for a real DMX interface, generalised here to plain text/JSON sensor readings instead of one fixed protocol.

No custom firmware protocol required beyond one line: have the board print each reading as its own newline-terminated line -- plain text, or a small JSON object -- over its regular serial/USB connection.
