Flying Fox Count

A counting aid for flying fox (bat) colony emergence and return, at sunset or sunrise. Point the camera at the sky — Outline mode redraws the whole feed as bright edge-lines on black, the same effect used elsewhere in this suite, which makes moving bats stand out as bright loops against the dark. Detection tracks each edge-blob frame to frame and only circles the ones actually moving in a direction, the way bats crossing the sky do, not static clutter like a tree or a wire junction. Tap the tally yourself by default; once the camera's fixed in place, Auto count can add each tracked crossing for you. Work in progress either way: this does not reliably count for you — check it and correct it by hand.

This browser can't record video, so sessions will run live-only — everything above still works, there's just nothing to review afterwards.
